# Audio sources

Các file trong thư mục này được tự host để tránh phụ thuộc host âm thanh ngoài.

- `rain-and-thunder.ogg`: [Wikimedia Commons — Rain and thunder.ogg](https://commons.wikimedia.org/wiki/File:Rain_and_thunder.ogg), phát hành public domain bởi tác giả Caesar.
- `turning-a-page.ogg`: [Wikimedia Commons — Turning a page.ogg](https://commons.wikimedia.org/wiki/File:Turning_a_page.ogg), public domain bởi tác giả planish.
- `bird-singing.ogg`: [Wikimedia Commons — Bird singing.ogg](https://commons.wikimedia.org/wiki/File:Bird_singing.ogg), public domain bởi tác giả jc.
- `synthetic-bell.ogg`: [Wikimedia Commons — Synthetic bell sound.ogg](https://commons.wikimedia.org/wiki/File:Synthetic_bell_sound.ogg), CC0 1.0 Universal Public Domain Dedication bởi tác giả Achim55.

Các file được dùng như âm nền/âm thanh tích hợp trong ứng dụng, không lấy link YouTube `watch` làm `src` cho thẻ `<audio>`.
